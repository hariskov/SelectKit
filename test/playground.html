SelectKit playground

Manual test page. Each phase adds a section. Serve with npm run playground.

Phase 0 — Skeleton

If Floorp opened on this page with the SelectKit icon in the toolbar, the extension is loaded.

Check for errors: about:debugging#/runtime/this-firefox → SelectKit → Inspect → Console should say “SelectKit 0.2.0 loaded”.

Phase 1 — Settings

  1. Click the SelectKit toolbar icon → settings open in a new tab.
  2. Defaults: English · EUR · Word wrapper on.
  3. “Convert prices to” is a dropdown with EUR, USD, RON and BGN.
  4. Every change shows “Saved” top right.
  5. Change a few values, then about:debugging → SelectKit → Reload, reopen settings → values kept.
  6. Switch the system between light and dark → page stays readable.

Phase 2 — Popup at the mouse (Copy only)

  1. Select any part of this sentence with the mouse → a dark popup with Copy appears just below-right of the cursor.
  2. Click Copy → it says “Copied” and closes; paste somewhere to check the text. The selection on the page stays.
  3. Select again, then close the popup each way: Esc, scrolling, clicking elsewhere on the page.
  4. Double-click a word and triple-click a paragraph → popup appears both times.
  5. Select text in each of these → no popup (text fields and editors are left alone): select me in the editable span
  6. Select text in a field, then select normal page text → the popup appears again for the page text.

Select this right-aligned text near the edge of the window → the popup stays fully inside the window.

Hostile CSS: this page has rules that set every button to hot pink 30px, every div with a class to hidden, and Comic Sans on this block. Select this text → the popup must look exactly like everywhere else.

Iframe: select text inside the frame below → popup appears inside the frame.
